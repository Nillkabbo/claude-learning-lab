MCP in Claude Code

Connect the protocol's tools, resources, and prompts — with trust boundaries on.

≈ 12 minutes + drill Claude Code Guide Hands-on by design

Claude Code is an MCP client: connect servers (local or remote) and their tools join your session. What to hold onto from Track 1:

  • Three primitives: tools (model-executed actions), resources (data the client reads), prompts (templates you invoke).
  • The trust model (0021): servers are untrusted code+metadata — consent before local installs (the exact, untruncated command), progressive scopes, never token passthrough, never session auth.
  • Org control: managed settings can control which MCP servers are allowed at all (official admin page).

The quickstart page walks a first connection end-to-end; the connector page covers remote servers and auth.
