Every platform: desktop, mobile, web, Chrome, computer use

One assistant, every surface — and a rule for choosing between them.

The official comparison, learned as a decision table:

PlatformBest forDistinct capability
CLITerminal work, scripting, serversFull feature set; the Agent SDK and scripting are CLI-only
DesktopVisual review, parallel sessionsDiff viewer, app preview; computer use + Dispatch (Pro/Max)
VS CodeStaying in the editorInline diffs, integrated terminal, file context
JetBrainsIntelliJ/PyCharm/WebStorm…Diff viewer, selection sharing (runs the CLI in the IDE terminal)
WebLong tasks needing little steering; work continuing while you're offlineCloud-based, Anthropic-managed; sessions continue after disconnect
MobileStarting/monitoring away from your machineA thin client into cloud sessions; Remote Control for local ones

Away-from-terminal options: Dispatch (message from mobile → runs on your Desktop), Remote Control (drive a local session from claude.ai/code or mobile), Channels (Telegram/Discord/your server → your CLI), Slack (runs in Anthropic's cloud), self-hosted (your org's infrastructure, Team/Enterprise), scheduled tasks.

The mixing rule: one project, many surfaces — configuration, project memory, and MCP servers are shared across local surfaces. Pick per task, not per identity.
