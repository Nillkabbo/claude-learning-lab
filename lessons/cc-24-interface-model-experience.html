Your interface & model experience

Make the tool yours: terminal, status line, styles, speed, and the advisor.

≈ 12 minutes + drill Claude Code Guide · Phase F Hands-on by design

Two clusters the docs dedicate whole sections to:

  • Interface — configure your terminal; fullscreen rendering; customize the status line and keyboard shortcuts; voice dictation; screen-reader support. Small levers, daily comfort.
  • Model experience — model configuration (which Claude, per task); output styles (the response persona); fast mode for speed; and the advisor tool: escalate a hard decision to a stronger model mid-generation — the two-model pattern from Track 1's research, productized.

The operator's frame: these are the ergonomic and economic dials — persona costs nothing, model choice costs money, fast mode trades quality for speed, the advisor spends big-model tokens only on the hard calls.
