Code review & CI/CD

Claude in the pipeline: reviewing PRs and scanning for vulnerabilities.

≈ 12 minutes + drill Claude Code Guide Hands-on by design
CI reviews every PR

The official CI surface (docs map): GitHub Actions (and with cloud providers, GHES, GitLab CI/CD), Code Review, and Claude Security for vulnerability scanning — plus catch security issues as Claude writes code.

  • Headless in CI is the same law as CC-12: claude -p with JSON output, contained permission modes, and explicit budgets — an automation without fences is an outage scheduler.
  • Review as a gate — invoke code review on PRs; findings arrive as comments. Pair with Track 1's eval discipline: the pipeline judges outcomes, not vibes.
  • Secrets stay secrets — deny rules and sandboxing apply in CI too; the org's managed settings travel with the pipeline.
