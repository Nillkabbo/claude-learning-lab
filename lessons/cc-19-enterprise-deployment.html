Enterprise deployment & gateways

Claude Code where the org says it runs: clouds, gateways, policy.

≈ 12 minutes + drill Claude Code Guide Hands-on by design
gateways + policy

The org-scale surface (official pages):

  • Clouds — Bedrock, Google Cloud's Agent Platform, Microsoft Foundry: authenticate and run against enterprise cloud deployments (CC-01's auth menu, at org scale).
  • Gateways — run Claude Code through a gateway: the apps gateway (Bedrock/AWS/GCP/Foundry behind it, with spend limits, deployment/ops guides) or other LLM gateways (connect, roll out, protocol reference).
  • Policy travels — managed settings deploy org-wide; server-managed settings and MCP-server access control keep the fences standing wherever the binary runs (CC-13/CC-14 at fleet size).
  • Network realities — enterprise network configuration, corporate launchers, dev containers: the official deployment pages are the checklist.

The architecture eye from Track 1: a gateway is a trust boundary — apply 0021's review (consent, scopes, no passthrough) to every hop you add.
