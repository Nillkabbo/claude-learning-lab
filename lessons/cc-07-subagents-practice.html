CC-07 · Phase B — Core user

Subagents in practice

Description-driven delegation, the built-ins, and agent view for the fleet.

≈ 12 minutes + drill Claude Code Guide Hands-on by design
delegation by description

0011's mechanics on your machine. Delegation is description-driven — write the description like a tool description (when, when-not, "use proactively"). Required frontmatter: name (lowercase-hyphens) + description; optional tools allowlist, model, maxTurns, skills, isolation: worktree. Edits hot-reload in seconds.

  • Built-ins: Explore (read-only, thoroughness levels), Plan (read-only context gathering), General-purpose (all tools).
  • Limits: 20 concurrent subagents, 3 layers of nesting by default.
  • Agent view (official page): manage multiple running agents — Phase C's fleet command starts here.
