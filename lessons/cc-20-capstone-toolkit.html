ship your toolkit

The final build. Everything in this guide composes into a personal (or team) toolkit, and shipping it is the mastery proof:

  1. Audit your week — the three tasks you repeat most in Claude Code sessions.
  2. Skillify one — a skill with frontmatter done right (argument-hint, allowed-tools, maybe context: fork).
  3. Agentify another — a subagent with a four-question delegation description and a minimal tool list.
  4. Automate the third — a hook (context injection, formatting, or audit) that fails safe, or a scheduled headless run with fences.
  5. Package it — a plugin manifest, so it installs with one command; publish to a team marketplace if you have one.

The review bar (from Track 1): every artifact passes its own validator; every automation has a budget; every "never" has an enforced layer. That's a toolkit.
