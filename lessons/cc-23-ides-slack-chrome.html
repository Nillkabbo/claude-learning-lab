IDEs, Slack, and Chrome

Meet your team where it already is.

≈ 12 minutes + drill Claude Code Guide · Phase F Hands-on by design
  • VS Code — inline diffs, the integrated terminal, file context in the editor. JetBrains (IntelliJ, PyCharm, WebStorm…) — diff viewer and selection sharing (select code, share it as context); under the hood it runs the CLI in the IDE's terminal, so third-party providers work.
  • Slack — Claude responds to @Claude mentions in team channels; those sessions run in Anthropic's cloud, not your machine. Claude Tag gives the org a shared @Claude identity with admin-configured access (Team and Enterprise).
  • Chrome — Claude controls your logged-in browser: testing web apps, filling forms, automating sites without an API.

The architecture eye from Track 1: every integration is a trust boundary — who authenticates, what the surface can reach, what's logged (0021's review applies to Chrome and Slack exactly as to MCP).
