CC-11 · Phase C — Power user

Parallel work: worktrees, agent view, session teams

Many Claudes, many branches, one operator.

≈ 12 minutes + drill Claude Code Guide Hands-on by design
parallel worktrees

The official parallel stack (from the docs map, explored hands-on):

  • Worktrees — run parallel sessions in isolated git worktrees: each session works its own branch and checkout, so file conflicts are structurally impossible. Subagents can request isolation: worktree too.
  • Agent view — the fleet console: manage multiple running agents, their states and outputs, from one place.
  • Orchestrate teams of sessions & message your other sessions — sessions that coordinate: one plans, others execute, messages pass between them (the official dynamic-workflows pages).

This is Track 1's orchestrator-workers pattern (0015) at the tooling layer — same laws: isolation before parallelism, synthesis after, budgets everywhere.
