Claude Code on the web: routines & ultrareview

The cloud surface — where sessions outlive your laptop.

≈ 12 minutes + drill Claude Code Guide · Phase F Hands-on by design

The web surface lives at claude.ai/code, and sessions are first-class citizens across surfaces: --cloud and --teleport move sessions between web and terminal; you manage, share, and even auto-fix pull requests from the cloud.

  • Routines — "a saved Claude Code configuration: a prompt, one or more repositories, and a set of connectors, packaged once and run automatically." Pro/Max/Team/Enterprise; created from the web (claude.ai/code/routines), the desktop app, or the CLI — all writing to the same account. Fire on schedules, GitHub events, or API calls; mobile push notifications ping your phone.
  • Ultrareview — /code-review ultra: a deep, multi-agent review in the cloud — a fleet of reviewer agents in remote sandboxes reviewing your branch in parallel (security, correctness, …) to find and verify bugs before you merge.
  • Scheduled tasks — re-run a prompt on an interval: poll a deployment, babysit a PR, check a long build.
