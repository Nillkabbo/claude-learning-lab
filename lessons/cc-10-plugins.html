CC-10 · Phase C — Power user

Plugins: packaging power

Skills, agents, hooks, and MCP servers — shipped as one installable unit.

≈ 12 minutes + drill Claude Code Guide Hands-on by design
plugin = one installable

Plugins bundle the whole artifact map: skills, agents, hooks, and MCP servers, namespaced (plugin-name:skill-name). The lifecycle to know:

  • Discover and install from marketplaces; orgs can run their own — and constrain versions, recommend plugins from the CLI, or recommend for the whole org (official distribution pages).
  • Create: a plugin is a directory with the artifacts you already know how to write (Phases B and C), plus a marketplace manifest to publish.
  • Trust and control: plugin hooks run while enabled; org policy can allowManagedHooksOnly; ${{CLAUDE_PLUGIN_ROOT}} and ${{CLAUDE_PLUGIN_DATA}} give plugins portable paths.

Before writing your own, audit one popular plugin: what it ships, what it hooks, what it asks for. The audit habit transfers.
