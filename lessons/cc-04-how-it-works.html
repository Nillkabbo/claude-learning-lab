How Claude Code works: context, caching, cost

The harness is an API client with excellent manners — knowing which ones is the lesson.

≈ 12 minutes + drill Claude Code Guide Hands-on by design
the context budget

Claude Code is the agent loop (Track 1's 0005/0012) productized around your repo: it manages the conversation, executes tools, and — crucially — manages the context window for you. What you should still know:

  • Everything counts — CLAUDE.md files, tool results, file reads all consume the window (Law 7), and cached tokens still count even though they cost a tenth.
  • Compaction is automatic near the limit: older turns summarize so the session continues (0008's primary strategy, built in).
  • Prompt caching keeps the stable prefix cheap — which is why big system setups don't bankrupt you, and why /context before and after big changes is an operator habit.

The official pages — Explore the context window and How Claude Code uses prompt caching — turn these into specifics; read both with /context open.
