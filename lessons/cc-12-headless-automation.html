Headless & scheduled: -p, JSON, /goal, routines

Claude Code as a programmable component, not a conversation.

≈ 12 minutes + drill Claude Code Guide Hands-on by design

Headless (0012-verified): claude -p "prompt" runs non-interactive; --output-format json makes it scriptable — the official pattern for languages and pipelines without an SDK. Compose with -c/ -r for continuity.

The automation stack (official pages, hands-on):

  • /goal — keep Claude working toward a goal across turns, not just one prompt.
  • Routines & schedules — run prompts on a schedule (web/desktop pages).
  • Channels — push events into running sessions; Slack integration rides this rail.

Operator's rule from Track 1: unattended power needs contained permission modes and budgets — automation without fences is an outage scheduler.
