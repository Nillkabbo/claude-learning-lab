Memory craft: CLAUDE.md in depth

The file that teaches every future session — and the directory that houses it.

≈ 12 minutes + drill Claude Code Guide Hands-on by design

Everything 0009 taught, at operator depth. The scope ladder: managed policy → user (~/.claude/CLAUDE.md) → project (./CLAUDE.md, committed) → local (CLAUDE.local.md, gitignored). Loading is recursive upward from where you launch, concatenated so closer files read last (last = loudest); subdirectory files load on demand.

  • @path imports nest up to four hops, resolve relative to the importing file, and backticks keep them literal. Import @AGENTS.md for agent-file compatibility.
  • Auto memory: notes Claude writes itself, indexed via MEMORY.md — context, not enforcement, like all memory.
  • Craft: under 200 lines; add an instruction when Claude makes the same mistake twice; specific commands, not vibes; contradictions make Claude pick arbitrarily; procedures belong in skills, not CLAUDE.md.
  • /memory lists and edits every scope; /init bootstraps a starter file with improvement suggestions; /context proves what actually loaded.

The .claude directory tour (official page) covers the rest of the house: settings.json, agents/, skills/, hooks — Phase B's map.
