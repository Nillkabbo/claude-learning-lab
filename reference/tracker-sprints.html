Sprint mode · the engagement fix

Tracker in 12 sprints

Ten minutes each. Three commands each. You paste the output; I coach the next three. This is how the doing finally starts.

12 × 10 minutes You run commands · I coach Ends at: your Tracker v1.0
The rule of this mode No sprint is "done" until you've pasted its output to your agent. Not the right output — your output. Wrong output is the best coaching material there is. The story chapters remain the why; these sprints are only the doing, shrunk until doing is easier than not.

Sprint 0 — the door (5 min)

claude --version

Version prints? Skip to Sprint 1. Error? Run the install for your platform (curl -fsSL https://claude.ai/install.sh | bash on macOS/Linux), then claude once to log in. Paste: the version line (or the error).

Sprint 1 — the repo (10 min)

mkdir my-tracker && cd my-tracker
git init
claude

Inside the session, type: "Create a README saying this is a tiny issue-tracker CLI in Python. Just the README." Approve the write (read it first). Exit, commit: git add -A && git commit -m "add: readme". Paste: your git log --oneline.

Sprint 2 — the first behavior (10 min)

claude, then: "Add tracker.py with an `add` command: `python3 tracker.py add some text` appends {id, text, status} to tasks.json with auto-incrementing ids, prints the id. Under 40 lines." Read the diff. Approve. Run it: python3 tracker.py add survive sprint two. Paste: the printed id + your one-line review of the diff.

Sprint 3 — break it on purpose (10 min)

python3 tracker.py add fix the "login" bug

Quotes eat arguments (Ch 2's story). Back in claude, Shift+Tab to plan mode: "That input breaks — plan a fix: join argv fragments, and make writes atomic (temp file + replace) so a failed write can't truncate tasks.json." Read the plan, approve, read the diff. Paste: did the plan mention both fixes? Your call on anything you'd amend.

Sprint 4 — list + close (10 min)

Two pointed asks (separate prompts, read both diffs): "add `list` — print id [status] text", then "add `close <id>` — mark done; list shows [x]". Prove it: add three tasks, close one, list. Paste: the list output.

Sprint 5 — the file that teaches (10 min)

Run /init. Cut its draft to ≤15 lines: run commands, conventions, a Do not section (≥2 real rules). Commit. Paste: your CLAUDE.md's Do-not section.

Sprint 6 — the Friday chore (10 min)

Create .claude/skills/release/SKILL.md (copy the shape from the worked example, adapt it). In a session: /release v0.2 — with one failing test on purpose first, to watch it abort. Paste: the abort, then the successful run.

Sprint 7 — the guardrails (10 min)

Write .claude/settings.json with allow/ask/deny (adapt the worked example). Then try to make Claude run git push origin main and watch it refuse. Paste: the refusal.

Sprint 8 — tags + search (10 min)

Plan-first ask: "add `tag <id> <tag>` and `search <text>` matching text and tags, case-insensitive." Add rotate keys #infra, then search infra. Paste: the search hit. Tag v0.3.

Sprint 9 — the suite (10 min)

Ask for tests mirroring the worked example's spirit: ids increment, quoted text survives, failed save never truncates. Run python3 -m unittest discover until green. Paste: the OK line.

Sprint 10 — CI (10 min)

Add .github/workflows/ci.yml (adapt the worked example). Push to a fresh GitHub repo; watch the check run. Paste: the green check URL.

Sprint 11 — the night shift (10 min)

Copy-adapt nightly.py; run it in dry-run. Schedule it (cron line: 0 9 * * *). Break one test before bed; read the morning report. Paste: the report.

Sprint 12 — v1.0, yours (10 min)

/release v1.0. Then the graduation line, in your repo: git log --oneline — every commit yours, every diff read. Paste: the log. That paste is the ledger's first real entry, and the moment this whole workspace did what it was built for.
