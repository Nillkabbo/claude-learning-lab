Start with The Story instead Prefer concepts through narrative and a project that grows chapter by chapter? The Story is the primary path: 12 chapters, one real project (Tracker) — this 26-lesson guide is the reference manual behind it. Come back here whenever a chapter leaves you wanting depth.

How this track works

  • Same loop as Track 1: read the lesson, take its quiz, do the (genuinely hands-on) drill, report, say "next CC lesson".
  • Every CC lesson cites its official doc page — the docs are the source of truth; the lessons are your guided tour.
  • Drills run on your machine: this track is about muscle memory as much as knowledge.
